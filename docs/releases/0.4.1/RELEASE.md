# Remote Hosts 0.4.1

本轮源码与两平台构建通过，NAS网关和MacBook已实际运行0.4.1。Studio更新器发现其他活动任务，在安装前停止，仍运行0.4.0。MacBook就绪与只读工作区分页已验收；综合读写/文件验收调用被宿主在执行前拒绝，三目标发布尚未全部验收。准确状态见 `deployment.json`、`deployment-r1.json` 和 `macbook-runtime-proof.json`。

## 修复与增强

| 方向 | 本版变化 |
|---|---|
| 恢复请求竞争 | 短数据库事务提前取得写意向；8个相同恢复请求并发时只形成一个持久代际，避免读转写锁升级失败。 |
| 授权刷新 | 相同幂等恢复请求可替换过期URL，不创建新任务或代际；旧请求不能覆盖新代际的授权，已完成或取消任务也不会被重新激活。 |
| 回执代际 | 只有低于当前代际的回执被确认为过期；未来代际必须拒绝，缺少新代际的结果不能完成新任务。比较与结果落盘在同一SQL更新中完成。 |
| 取消进度 | 取消结果不再被外层执行器写成completed进度；结果状态与进度终态保持一致。 |
| 下载范围 | If-Range不匹配/弱验证器回退为完整200响应；正确ETag保持206范围响应，并支持单个后缀范围。 |
| 工作区交接 | 增加active_only、状态汇总和终端keyset分页；游标绑定工作区及过滤条件，活跃记录优先，截断结果可以继续读取。 |
| 发布输入与收尾 | 正式包包含release_receipts.py：验证已完成构建与产物哈希、分别有界观察双方原更新器结果、持久阶段意图与并发互斥，防止重复安装。 |

工具仍为18项；现有调用兼容。单文件64 MiB和原有根目录、鉴权、哈希、原子发布保护均保留。confirmed_bytes单独变化推进观察游标的行为在0.4.0已存在，本轮增加回归，不作为新增修复宣称。

## 保留范围

工作区交接仍不是完整Git证据或聊天记忆。恢复控制短事务改进不等于所有SQLite热点都已优化。生产发布执行器遇到未知结果不会盲目重放；独立观察确认后方可接续。更广泛的设备故障、磁盘回收和原生宿主能力刷新继续保留在统一问题清单，不因版本号变化自动关闭。

本轮没有创建分支、提交或推送Git；旧版本包和回退备份保留。
