## 本轮改造

### RH-038：固定输入不再要求每轮更换编译路径

新增 `scripts/build_slot.py`，在受管理的稳定 checkout 内增量同步固定快照；未变化的内容和可执行属性保持原文件、inode及mtime。只删除上次受管理清单中本次移除的文件。意外新增源文件、被修改的槽内源码或符号链接会拒绝同步，不通过清空目录掩盖问题。

单个操作系统文件锁覆盖同步、验证、两平台构建和打包。构建执行使用专用稳定 CARGO_TARGET_DIR，不复用其它编辑任务会写入的最终二进制文件。首次建立独立缓存需要冷构建，不承诺首轮会更快；后续保留同路径缓存，仍完整执行验证而非跳过测试。

### 构建状态不再只有running

新增 `scripts/release-code.py`，按固定命令依次执行验证、Mac ARM64发布构建、Linux AMD64 musl构建和打包。记录每一阶段的退出码、日志哈希、阶段耗时及原任务报告。每约3秒观察当前进程后代的CPU计数和实际编译日志，不采集命令参数。

状态区分 cpu_active、output_advanced、cargo_lock_wait_hint 和 quiet_not_proven_stalled。无输出不等于卡死，CPU活动也不等于必然正确。验证阶段读取真正的Cargo子阶段日志，不仅观察外层阶段汇总。`--status` 只读原报告；重复同报告不会启动新构建；同槽不同报告被占用时返回原持有者信息。

超时/中断停止自己拥有的进程组，保留失败记录和输出。它不是限制仓库代码的安全沙箱，也没有实现机器掉电后的所有自动恢复或跨平台统一进程树回收。

### RH-046：升级预检修复进入正式发布包

本版收录0.3.4恢复时单独验证并实际使用的更新器修复：HTTP/DNS/TLS/超时等安全分类、phase与service_changed、只对临时故障做最多三次同目标只读重试。401/403、证书验证和身份冲突不靠自动重试绕开。固定脚本身份、HTTPS和设备鉴权保留，成功更新仍必须确认稳定回连。
