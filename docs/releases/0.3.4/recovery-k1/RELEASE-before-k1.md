## 本轮实现

操作的本地最终结果和待发送回执在同一个 SQLite 事务里持久保存。执行 worker 完成后即可释放，不继续等待 HTTP 回执响应。独立、有界的发送器只发送已经保存的原结果，不执行代码、重建文件或重新创建工作区。

收到 HTTP 200 还不够，必须解析到 accepted=true 才删除待发送记录；本地幂等日志不删除。丢失网络、5xx、429或无法确认的响应按有界退避继续补送，进程重建后仍能领取未确认记录。每次发送使用独立租约标识，旧响应不能删除后来尝试的记录。

400/401/403/404/405/409/410/413/422 等明确拒绝保留为 blocked，不无限重放，也不将它们伪装成业务执行失败。待发队列绑定原设备和原网关地址，改了设备或目标不能把历史结果自动发给新位置。blocked 的授权恢复入口及完整跨会话 fencing 仍属于 RH-024 后续范围。

网关通过经过设备鉴权的轮询保存回执队列统计。devices_list 可返回 pending、blocked、sending、最早创建时间及新鲜度，不暴露回执内容或凭据。统计异常不应阻止 Agent 领取业务任务。sending 表示持久租约记录，进程重建后可能包括尚未过期的旧租约，不等于当前线程数量。

## 范围限制

本轮不是文件分片续传，也不是任意 shell 副作用的“恰好一次”证明。副作用发生后、结果持久化前进程崩溃，仍按 outcome_unknown 处理，不自动重执行。长期队列容量/保留策略、人工解除blocked、完整session/generation隔离、跨网关数据库回滚矩阵仍需后续工作。
